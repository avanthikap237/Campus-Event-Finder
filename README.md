# Campus Event Finder

A beginner-friendly front-end project that helps students browse sample campus events.

## Features
- View event cards with dates, times, venues and descriptions
- Search events by title, description or venue
- Filter events by category
- Responsive layout for desktop and mobile
- Demo "I'm interested" interaction

## Built with
- HTML
- CSS
- JavaScript

## Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it with a browser.

## Important note
This is a front-end demonstration using sample event data. The interest button displays a demo message; it does not submit a real registration. Update the sample events and add a real registration service before using it for actual campus events.
